# Pre-send check

Run on every correspondence draft after the review loop and before the user sees it. Confirm each item. Name any item the draft does not meet. Never hand the user a draft as finished while one is unmet. Say which one is missing and why, or ask for what is needed to fix it.

1. Thanks for something specific, not "thanks for the time." (Outreach: the "why" names something specific about the company instead.)
2. Reacts to something the person actually said or sent.
3. States plainly what the user wants or what interests them.
4. Has its own warm closing line.
5. Every fact about the user's background is verified against `profile.md` or the master resume.
6. Correct mode for what is being produced (correspondence for anything addressed to a person).

Show the result as six short lines, each "met" or the reason it is not. One line at most per item. No commentary beyond that.

If the draft is a cover letter, item 1 becomes "names the specific thing about the role that interests the user" and item 5 includes the roster pass.
